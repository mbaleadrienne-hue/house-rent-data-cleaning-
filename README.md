# House Rent Dataset - From Messy Data to Dashboard

**Context:** 4746 rows raw dataset - misaligned columns, inconsistent city names, missing rents, duplicates. Unusable for analysis.

**What I did:**
- Data Cleaning with Python (Pandas) & Power Query
- Standardization: city names, property types, rent values
- Removed outliers & duplicates
- Built 3 Pivot Tables: Revenue by City / by Property Type / by Month
- Built Final Dashboard: $128.4K total revenue tracked (+22% growth)

**Stack:** Python, Pandas, Excel, Power Query

**Result:** From unusable file to analysis-ready dataset in <24h. Method is replicable for any SME sales data.
